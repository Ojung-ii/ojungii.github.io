## 원본 자료 기반 정합성 수정

- **StAR**: Table 2 의 −5.47/−3.26/−2.53는 상대 F1 변화율(%)이며 F1 포인트가 아닙니다. Table 1에서 HotpotQA 51.14→52.80, MuSiQue 예외(26.81 vs 26.58)를 구분합니다.
- **GRef-RAG**: 문서/언급 이종 그래프와 일반 entity triple KG를 구별하고 67.8% 토큰 감소는 비교 조건을 붙였습니다.
- **MoT**: arXiv 2607.28979v2의 Llama/Gemma/Qwen 실험과 Figure 13/14를 구분합니다.
- **MPR-CiteG**: Q 확장, S 동의어, F 균형, G 한영 번역(NLLB-200), ~270 candidates → Cross-Encoder top 50 → 생성 prompt top 10으로 바로잡았습니다.
- **철강 RAG**: 2024년 구현 완료 기능과 수기/저화질 OCR 및 현업 정성 검증 과제를 분리합니다.
- **BioAI**: Slide 11 GCN/GAT 비교, Slide 12 global feature stage와 Slide 13 최종 0.92 / 0.90은 다른 실험 단계이며 인과 ablation처럼 합치지 않습니다.

## 매체 선택 원칙

원본 논문 Figure를 전부 캡처해 작게 붙이면 읽는 사람이 논문 PDF만큼 확대해야 하고, 회사 내부 고객 정보 노출 우려도 있습니다. **원문 직접 활용이 더 정확한 수식·실험 그림은 원본 Figure 위치와 공개 논문 링크를 명시**하고, 웹은 핵심 수치·질의 사례·입출력 관계를 다시 읽기 쉽게 구성합니다. 비공개 원고와 고객 규격서·실제 원문 시트는 자동으로 공개하지 않습니다.

## 실질적인 미해결 범위

- 원본 논문의 모든 Figure를 개별 벡터 이미지로 원형 재게시한 것은 아닙니다.
- 고객 내부 PowerPoint의 실제 품질 검사 예시는 원본 이미지 재게시 전 공개 가능 여부 확인이 필요합니다.
- 30회 역할 기반 검토는 서로 다른 평가 렌즈의 검증 절차이지 실제 인간 전문가 30명이 평가했다는 의미가 아닙니다.
- 브라우저 자동검사에 통과하더라도 공개 전 사람이 원문·수치·최종 시각을 한 번 더 확인하는 것이 좋습니다.
